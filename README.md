# E-Reporting V4 — Functional UI Prototype

This version extends the V3 concept into a more functional prototype:
- dashboard and report list
- report detail
- report creation
- template management screen
- account screen
- Admin / User / Client demo role switcher
- QR client-signing flow (prototype modal)
- signature completion simulation
- responsive desktop/mobile layout

Backend/auth/database are intentionally not connected yet. Next step is Firebase schema + authentication + real QR signing.
